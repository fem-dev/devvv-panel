# داشبورد مانیتورینگ سخت‌افزار برای Marimo

یک داشبورد فارسی، راست‌چین و تیره برای نمایش اطلاعات پایهٔ سیستم و رویدادهای نشست، مستقیماً در Marimo Notebook.

## امکانات
- رابط فارسی RTL با کارت‌های آماری و تب‌های جداگانه
- نمایش سیستم‌عامل، معماری، پردازنده، RAM، فضای آزاد دیسک و میزان مصرف CPU/RAM
- تشخیص محدود GPU از طریق اطلاعات read-only سیستم‌عامل در Linux
- ترمینال نمایشی با وضعیت read-only
- گزارش رویدادهای نشست و دکمهٔ ثبت رویداد آزمایشی
- تست‌های واحد و GitHub Actions

## اجرا
Python 3.10 یا جدیدتر پیشنهاد می‌شود.

```bash
python -m venv .venv
# Linux / macOS
source .venv/bin/activate
# Windows PowerShell
# .venv\Scripts\Activate.ps1
pip install -r requirements.txt
marimo edit app.py
```

برای اجرای read-only:
```bash
marimo run app.py
```

## سلول‌های Marimo
در `app.py` شش سلول شماره‌گذاری‌شده وجود دارد:
1. کتابخانه‌ها و فضای رویدادهای نشست
2. پوستهٔ گرافیکی فارسی و راست‌چین
3. جمع‌آوری خواندنی مشخصات سیستم
4. ثبت رویداد آزمایشی
5. ترمینال نمایشی و گزارش رویدادها
6. چیدمان تب‌ها و کارت‌های داشبورد

## مرزهای ایمنی و حریم خصوصی
- برنامه فقط اطلاعات پایهٔ سیستم را می‌خواند.
- هیچ نرم‌افزار استخراجی دانلود یا اجرا نمی‌شود و هیچ اتصال استخری ساخته نمی‌شود.
- هیچ shell command، تغییر تنظیمات سیستم، دسترسی مدیریتی یا پردازش پس‌زمینه‌ای انجام نمی‌شود.
- لاگ‌ها فقط در حافظهٔ نشست نگه‌داری می‌شوند و پس از پایان نشست باقی نمی‌مانند.

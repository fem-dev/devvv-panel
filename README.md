# پنل مدیریت ماینر برای Marimo

داشبورد فارسی و راست‌چین برای بررسی سازگاری سخت‌افزار، انتخاب نرم‌افزار استخراج، ساخت تنظیمات استخر و مشاهدهٔ لاگ‌ها در خود Marimo.

> **حالت ایمن نسخهٔ اولیه:** این پروژه سخت‌افزار را فقط به‌صورت خواندنی بررسی می‌کند، تنظیمات را اعتبارسنجی می‌کند و فرمان پیشنهادی را به‌شکل متن نمایش می‌دهد. هیچ فایل اجرایی ماینری دانلود یا اجرا نمی‌شود و هیچ پردازش استخراجی در پس‌زمینه شروع نمی‌شود. این محدودیت از اجرای ناخواستهٔ کد ناشناس، مصرف بی‌اجازهٔ منابع و آسیب حرارتی جلوگیری می‌کند.

## امکانات
- رابط کاربری فارسی، RTL و تم تیره
- داشبورد وضعیت سیستم و تشخیص CPU / RAM / GPU در حد اطلاعات در دسترس سیستم‌عامل
- فهرست نرم‌افزارها و الگوریتم‌های سازگار به‌همراه توضیح محدودیت‌ها
- فرم تنظیمات Pool، Port، Wallet، Worker و الگوریتم
- اعتبارسنجی ورودی‌ها و تولید فرمان نمونه بدون اجرا
- ترمینال نمایشی و لاگ رویدادهای محلی
- تست‌های واحد برای منطق کاتالوگ و اعتبارسنجی

## اجرا
Python 3.10 یا جدیدتر پیشنهاد می‌شود.

```bash
python -m venv .venv
# Linux / macOS
source .venv/bin/activate
# Windows PowerShell
# .venv\Scripts\Activate.ps1
pip install -r requirements.txt
marimo edit app.py
```

یا اجرای read-only:
```bash
marimo run app.py
```

## سلول‌های Marimo
در `app.py` سلول‌ها با عنوان‌های فارسی و شماره مشخص شده‌اند:
1. تنظیمات و واردکردن ماژول‌ها
2. استایل و اجزای نمایشی
3. بررسی سخت‌افزار
4. کاتالوگ و پیشنهاد نرم‌افزار
5. فرم تنظیمات استخر
6. پیش‌نمایش فرمان (بدون اجرا)
7. ترمینال و گزارش رویدادها

## امنیت و حریم خصوصی
- اطلاعات کیف پول فقط در حافظهٔ نشست رابط کاربری می‌ماند و در فایل/لاگ نوشته نمی‌شود.
- هیچ shell command، دانلود باینری، اجرای ماینر، تغییر تنظیمات سیستم یا دسترسی مدیریتی انجام نمی‌شود.
- برای استفادهٔ واقعی، فقط نرم‌افزار را از وب‌سایت رسمی سازنده بررسی و دریافت کنید؛ هش و امضای فایل را نیز طبق راهنمای رسمی بررسی کنید.
- استخراج می‌تواند برق و گرما مصرف کند و به سخت‌افزار فشار وارد کند؛ دمای دستگاه و محدودیت‌های سازنده را جدی بگیرید.

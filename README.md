# پنل مدیریت ماینر برای Marimo

داشبورد فارسی و راست‌چین برای بررسی سازگاری سخت‌افزار، انتخاب نرم‌افزار استخراج، ساخت تنظیمات استخر و مشاهدهٔ لاگ‌ها در خود Marimo.

> **حالت امن نسخهٔ اولیه:** این پروژه سخت‌افزار را فقط به‌صورت خواندنی بررسی می‌کند، تنظیمات را اعتبارسنجی می‌کند و یک قالب عمومی فرمان را به‌شکل متن نمایش می‌دهد. هیچ فایل اجرایی ماینری دانلود یا اجرا نمی‌شود و هیچ پردازش استخراجی در پس‌زمینه شروع نمی‌شود.

## امکانات
- رابط کاربری فارسی، RTL و تم تیره
- داشبورد وضعیت سیستم و تشخیص CPU / RAM / GPU در حد اطلاعات در دسترس سیستم‌عامل
- کاتالوگ نرم‌افزارها، الگوریتم‌ها و منابع رسمی
- فرم Pool، Port، Wallet، Worker و الگوریتم همراه با اعتبارسنجی سازگاری
- پیش‌نمایش متنی فرمان عمومی؛ بدون اجرای shell
- ترمینال نمایشی و لاگ رویدادهای نشست
- تست‌های واحد و GitHub Actions برای بررسی کد

## اجرا
Python 3.10 یا جدیدتر پیشنهاد می‌شود.

```bash
python -m venv .venv
# Linux / macOS
source .venv/bin/activate
# Windows PowerShell
# .venv\Scripts\Activate.ps1
pip install -r requirements.txt
marimo edit app.py
```

برای اجرای read-only:
```bash
marimo run app.py
```

## سلول‌های Marimo
در `app.py` هشت سلول مشخص و شماره‌گذاری شده‌اند:
1. واردکردن کتابخانه‌ها و ساخت فضای رویدادهای نشست
2. پوستهٔ گرافیکی فارسی و تم تیره
3. تشخیص خواندنی سخت‌افزار
4. کاتالوگ و پیشنهاد ماینر
5. فرم تنظیمات استخر
6. اعتبارسنجی و ساخت پیش‌نمایش
7. ترمینال نمایشی و لاگ‌ها
8. چیدمان نهایی تب‌ها و داشبورد

## امنیت و حریم خصوصی
- کیف پول و رمز استخر در فایل یا لاگ ذخیره نمی‌شوند؛ رمز استخر در ورودی مخفی نمایش داده می‌شود.
- هیچ shell command، دانلود باینری، اجرای ماینر، تغییر تنظیمات سیستم یا دسترسی مدیریتی انجام نمی‌شود.
- پیش‌نمایش فرمان یک قالب عمومی است؛ آرگومان‌های واقعی بین ماینرها متفاوت‌اند.
- برای دریافت نرم‌افزار، فقط منبع رسمی را بررسی کنید و هش/امضای انتشار را طبق مستندات سازنده اعتبارسنجی کنید.
- استخراج می‌تواند برق و گرمای زیادی مصرف کند و به سخت‌افزار فشار وارد کند؛ دما و محدودیت‌های سازنده را جدی بگیرید.
